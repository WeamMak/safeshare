# SafeShare

**SafeShare** is a real-time AI-powered privacy protection system that detects and redacts sensitive information during screen sharing before transmission.

## Tech Stack

- **Languages:** C++, Python
- **AI & Computer Vision:** PyTorch, OpenCV
- **Systems:** Linux, WebRTC, Multithreading

## Planned Features

- AI-powered sensitive information detection
- Real-time screen capture and redaction
- Secure video streaming
- Low-latency processing and memory optimization
- Privacy protection with fail-closed behavior
