# SafeShare

**SafeShare** is a real-time AI-powered privacy protection system designed to detect and redact sensitive information before it is transmitted during screen sharing.

## Problem
Screen sharing can unintentionally expose passwords, API keys, personal information, and confidential data.

## Solution
SafeShare aims to analyze screen content in real time, identify sensitive information using computer vision and deep learning, and prevent its exposure through automatic redaction.

## Tech Stack (Planned)
- **Languages:** C++20, Python
- **AI & Computer Vision:** PyTorch, OpenCV, OCR
- **Systems:** Linux, WebRTC, Multithreading
- **Build & Development:** CMake, Ninja, Git
